# Paw-Reader

A fast, fully client-side swipeable feed reader for Pawchive, designed with mobile-first smooth scrolling, keyboard navigation, and seamless media wrapping.

## Features
- **Swipeable Carousel**: Smoothly swipe through images and videos with responsive touch tracking and CSS snapping.
- **Native Keyboard Support**: Navigate the feed using WASD or Arrow Keys.
- **Auto-Hide Interface**: Non-intrusive UI that hides when not needed and reveals on hover/scroll up.
- **Media Wraparound**: Sliders naturally wrap around from the last image to the first image seamlessly.
- **Cloudflare Worker Backend**: Runs 100% in the browser by routing API requests securely through a Cloudflare Worker proxy, completely eliminating the need for a local backend server.
